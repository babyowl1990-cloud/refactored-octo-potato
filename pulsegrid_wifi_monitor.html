Background Monitoring PWA

InstallChecking eligibility…
Service WorkerRegistering…
Wake LockOff
Reality check: installing this does not give it true background execution. No browser lets a web app run continuously once its window is fully closed or the OS suspends it — that's a platform boundary every PWA hits, not a limitation of this build. What you actually get: an app-like standalone window, and on some browsers, monitoring that survives being minimized a bit longer than a bare tab — especially paired with the wake lock above, which only holds while the tab stays visible/foreground. For genuine always-on monitoring, that's a job for a small script on a machine that's always on (cron/systemd), not a browser tab.
